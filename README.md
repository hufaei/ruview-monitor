# RuView Monitor

RuView Monitor 的公开 Dashboard 与 Windows Agent 下载仓库。

- Dashboard：[hufaei.github.io/ruview-monitor](https://hufaei.github.io/ruview-monitor/)
- Windows Agent：[`v0.2.0-preview`](https://github.com/hufaei/ruview-monitor/releases/tag/v0.2.0-preview)
- 直接下载：[RuView Remote Agent 0.2.0](https://github.com/hufaei/ruview-monitor/releases/download/v0.2.0-preview/RuView-Remote-Agent-0.2.0-unsigned-technical-preview-win-x64.exe)

Agent 是无需安装 Python 或 RuView 的 Windows x64 单文件程序。首次启动使用
`ENR1` 登记一次；之后可上报当前 Wi-Fi 信号，或切换到固定模拟数据。硬件数据源
暂未开放。

> 当前版本是未签名技术预览，Windows 可能显示安全提醒。
